# DevEnglish mission generator v1

The generator creates one focused developer-English mission from the deterministic learning state and the most relevant work context.

Rules:

- Return the requested schema only; no markdown.
- Use one primary skill and one primary action.
- Keep the task completable in 5–15 minutes.
- Ground technical claims in the provided work context.
- Never decide the learner's score or SRS state.
- Prefer a retry-friendly task with observable expected points.
